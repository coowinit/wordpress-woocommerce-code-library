[Form] 根据城市分配邮件收件人

中风险

用于表单提交后，根据用户选择的城市，把邮件发送给不同代理商或公司主邮箱。

  • 适用文件：functions.php 或自定义插件
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：表单 / 邮件路由 / 城市代理
PHP 
function get_recipient_by_city($city) {
    $default_email = 'company@example.com';

    $city_email_map = [
        'Quebec'   => 'quebec-agent@example.com',
        'Montreal' => $default_email,
        'Toronto'  => $default_email,
        'Other'    => $default_email,
    ];

    return $city_email_map[$city] ?? $default_email;
}
公开仓库中请使用示例邮箱，不要保存真实客户邮箱或公司内部邮箱。

中风险

  • 适用文件：functions.php / woo-swatches.js / woo-swatches.css
  • 代码类型：PHP / JavaScript / Term Meta
  • 更新时间：2026-06-04
  • 标签：变体 / 色卡 / 场景图 / attribute_pa_xxx
TEXT 
颜色属性识别：
- color
- colour
- pa_xxx_color
- pa_xxx_colour

颜色 term meta：
- coo_swatch_hex       # 色卡颜色值
- coo_swatch_image_id  # 色卡缩略图

[v1.0.2] 后台 Page Settings 小插件模板

中风险

用于把联系人、电话、邮箱、社媒链接、Banner 等全站通用信息集中放到后台设置页，前台通过 get_option 调用。

  • 适用文件：自定义小插件
  • 代码类型：PHP / Settings API
  • 更新时间：2026-06-04
  • 标签：后台设置 / get_option / 小插件
php 
class My_Page_Settings {
    public function __construct() {
        add_action('admin_menu', [$this, 'add_admin_menu']);
        add_action('admin_init', [$this, 'init_settings']);
    }

    public function add_admin_menu() {
        add_menu_page('Page Settings', 'Page Settings', 'manage_options', 'page_settings', [$this, 'page_layout']);
    }

    public function init_settings() {
        register_setting('settings_group', 'settings_name');
        add_settings_section('settings_section', '', '__return_false', 'settings_name');
        add_settings_field('phoneli', '联系电话', [$this, 'render_text_field'], 'settings_name', 'settings_section', ['id' => 'phoneli']);
    }

    public function render_text_field($args) {
        $options = get_option('settings_name');
        $id = $args['id'];
        echo '<input type="text" name="settings_name[' . esc_attr($id) . ']" value="' . esc_attr($options[$id] ?? '') . '">';
    }
}
权限建议优先使用 manage_options，除非明确需要编辑人员也能修改全站设置。

php 
add_action('wp_ajax_send_custom_form', 'my_send_custom_form');

function my_send_custom_form() {
    check_ajax_referer('custom_form_nonce', 'nonce');

    $name = sanitize_text_field($_POST['name'] ?? '');
    $email = sanitize_email($_POST['email'] ?? '');
    $message = sanitize_textarea_field($_POST['message'] ?? '');

    if (!$name || !$email) {
        wp_send_json_error(['msg' => 'Required fields are missing.']);
    }

    $to = 'company@example.com';
    $subject = 'New Website Inquiry';
    $body = '<p><strong>Name:</strong> ' . esc_html($name) . '</p>';
    $body .= '<p><strong>Email:</strong> ' . esc_html($email) . '</p>';
    $body .= '<p><strong>Message:</strong><br>' . nl2br(esc_html($message)) . '</p>';

    $headers = ['Content-Type: text/html; charset=UTF-8'];
    wp_mail($to, $subject, $body, $headers) ? wp_send_json_success() : wp_send_json_error();
}

add_action('pre_get_posts', function ($query) {
    if (is_admin() || !$query->is_main_query()) {
        return;
    }

    if ($query->is_search() || $query->is_author() || $query->is_tag() || $query->is_date()) {
