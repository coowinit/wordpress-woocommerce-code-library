WooCommerce 商城

[WooCommerce] 修改产品详情页加入购物车按钮文字

低风险

用于把产品详情页默认的 “Add to cart” 按钮文字修改为自定义文字，例如 “立即询价”。

  • 适用文件：子主题 functions.php
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：WooCommerce / 产品详情页 / 按钮文字
PHP 
add_filter('woocommerce_product_single_add_to_cart_text', function() {
    return '立即询价';
});
建议添加到子主题的 functions.php 文件中，避免主题更新后代码被覆盖。

WordPress 基础

[WordPress] 后台隐藏评论菜单

低风险

适用于不需要评论功能的企业站或商城站，后台隐藏评论菜单，减少误操作。

  • 适用文件：子主题 functions.php
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：WordPress / 评论 / 后台菜单
PHP 
add_action('admin_menu', function() {
    remove_menu_page('edit-comments.php');
});
这段代码只是隐藏后台评论菜单，不会删除数据库中的评论数据。

表单 / 邮件

[Form] 根据城市分配邮件收件人

中风险

用于表单提交后，根据用户选择的城市，把邮件发送给不同代理商或公司主邮箱。

  • 适用文件：functions.php 或自定义插件
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：表单 / 邮件路由 / 城市代理
PHP 
function get_recipient_by_city($city) {
    $default_email = 'company@example.com';

    $city_email_map = [
        'Quebec'   => 'quebec-agent@example.com',
        'Montreal' => $default_email,
        'Toronto'  => $default_email,
        'Other'    => $default_email,
    ];

    return $city_email_map[$city] ?? $default_email;
}
公开仓库中请使用示例邮箱，不要保存真实客户邮箱或公司内部邮箱。

安全排查

[Security] 检查 mu-plugins 目录中的 PHP 文件

中风险

用于服务器中快速查看 wp-content/mu-plugins 目录下的 PHP 文件，辅助排查可疑文件。

  • 适用位置：服务器 SSH
  • 代码类型：Shell
  • 更新时间：2026-06-04
  • 标签：安全 / mu-plugins / 可疑文件
Shell 
find wp-content/mu-plugins -type f -name "*.php" -maxdepth 2 -print
mu-plugins 是 WordPress 的必须使用插件目录，里面既可能有正常文件，也可能被攻击者利用，需要结合文件内容判断。

document.querySelectorAll('.copy-btn').forEach((button) => {
    button.addEventListener('click', async () => {
