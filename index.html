低风险

  • 适用文件：子主题 functions.php
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：WooCommerce / 产品详情页 / 按钮文字
PHP 
add_filter('woocommerce_product_single_add_to_cart_text', function() {

表单 / 邮件

[Form] 根据城市分配邮件收件人

中风险

用于表单提交后，根据用户选择的城市，把邮件发送给不同代理商或公司主邮箱。

  • 适用文件：functions.php 或自定义插件
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：表单 / 邮件路由 / 城市代理
PHP 
function get_recipient_by_city($city) {
    $default_email = 'company@example.com';

    $city_email_map = [
        'Quebec'   => 'quebec-agent@example.com',
        'Montreal' => $default_email,
        'Toronto'  => $default_email,
        'Other'    => $default_email,
    ];

    return $city_email_map[$city] ?? $default_email;
}
公开仓库中请使用示例邮箱，不要保存真实客户邮箱或公司内部邮箱。

WooCommerce 商城

[v1.0.1] 变体色卡与场景图库维护要点

中风险

主题支持把颜色属性变成色卡，并且可以给每个颜色 term 配置场景图库。

  • 适用文件：functions.php / woo-swatches.js / woo-swatches.css
  • 代码类型：PHP / JavaScript / Term Meta
  • 更新时间：2026-06-04
  • 标签：变体 / 色卡 / 场景图 / attribute_pa_xxx
TEXT 
颜色属性识别：
- color
- colour
- pa_xxx_color
- pa_xxx_colour

颜色 term meta：
- coo_swatch_hex       # 色卡颜色值
- coo_swatch_image_id  # 色卡缩略图
- coo_scene_gallery    # 当前颜色对应的场景图库

最关键：
Woo 原生 select name 是 attribute_pa_xxx
色卡按钮 data-attribute 也必须是 attribute_pa_xxx
如果写成 `pa_xxx`，前端看似选中色卡，但 WooCommerce 实际没有选中变体，提交时会丢失 variation 数据。

表单 / 邮件

[v1.0.1] Quote System 通用表单接入规范

中风险

Contact、Pricing、Product Details 右侧表单等非产品询盘，建议统一使用 `data-coo-inquiry-form` 接入通用 Ajax 入库接口。

  • 适用插件：coowin-quote-system
  • Ajax Action：coo_inquiry_submit_generic
  • 更新时间：2026-06-04
  • 标签：通用表单 / Ajax / 询盘入库 / Custom Fields
HTML 
<form data-coo-inquiry-form>
  <input type="hidden" name="_coo_source" value="contact">
  <input type="hidden" name="_coo_form_key" value="contact_page_main">
  <input type="hidden" name="_coo_form_title" value="Contact Us Form">
  <input type="hidden" name="_coo_required" value="name,email,message">
  <input type="hidden" name="_coo_labels" value='{"material_type":"Material Type"}'>

  <input type="text" name="name">
  <input type="email" name="email">
  <textarea name="message"></textarea>

  <input type="text" name="website" style="display:none" tabindex="-1" autocomplete="off">
  <button type="submit">Submit</button>
  <div data-coo-form-msg style="display:none"></div>
</form>
`_coo_required` 中的字段名必须和实际表单控件的 `name` 完全一致；非标准字段会进入 `meta_json.fields`。
