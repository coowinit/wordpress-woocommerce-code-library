[Assets] 正确加载主题 CSS / JS 并自动刷新缓存

低风险

使用 wp_enqueue_scripts 正确加载主题资源，并用 filemtime() 自动刷新浏览器缓存。

  • 适用文件：functions.php
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：资源加载 / filemtime / 缓存刷新
PHP 
function mytheme_enqueue_assets() {
    $css_file = get_theme_file_path('/assets/css/style.css');
    $js_file  = get_theme_file_path('/assets/js/main.js');

    wp_enqueue_style(
        'mytheme-style',
        get_theme_file_uri('/assets/css/style.css'),
        [],
        file_exists($css_file) ? filemtime($css_file) : '1.0.0'
    );

    wp_enqueue_script(
        'mytheme-main',
        get_theme_file_uri('/assets/js/main.js'),
        ['jquery'],
        file_exists($js_file) ? filemtime($js_file) : '1.0.0',
        true
    );
}
add_action('wp_enqueue_scripts', 'mytheme_enqueue_assets');
适合主题开发长期复用。get_theme_file_uri() 获取 URL，get_theme_file_path() 获取服务器文件路径。

[Recovery] 忘记管理员密码时临时新增管理员账号

高风险

仅限自有网站后台无法登录时的临时救急方法。通过 FTP 修改 functions.php，创建临时管理员账号。

  • 适用文件：functions.php
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：管理员恢复 / wp_create_user / 高风险
PHP 
function coowin_create_temp_admin_account() {
    $user  = 'temp_recovery_admin';
    $pass  = 'CHANGE_THIS_TO_A_STRONG_PASSWORD';
    $email = 'temp-admin@example.com';

    if ( username_exists( $user ) || email_exists( $email ) ) {
        return;
    }

    $user_id = wp_create_user( $user, $pass, $email );

    if ( is_wp_error( $user_id ) ) {
        return;
    }

    $wp_user = new WP_User( $user_id );
    $wp_user->set_role( 'administrator' );
}
add_action( 'init', 'coowin_create_temp_admin_account' );
登录成功后必须立即删除这段代码，并删除临时账号或修改为正式安全账号。公开仓库中不要保存真实用户名、密码和邮箱。

[Breadcrumb] 自定义面包屑导航核心逻辑

低风险

适合轻量企业站或简单主题，不依赖插件实现 Home / 分类 / 文章 / 页面 / 搜索 / 404 的基础面包屑。

  • 适用文件：functions.php + 模板文件
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：自定义面包屑 / is_single / is_category
PHP 
function coowin_breadcrumbs() {
    if ( is_front_page() ) {
        return;
    }

    echo '<nav class="breadcrumbs" aria-label="Breadcrumb">';
    echo '<a href="' . esc_url( home_url( '/' ) ) . '">Home</a>';

    if ( is_category() || is_single() ) {
        $categories = get_the_category();

        if ( ! empty( $categories ) ) {
            echo ' <span>/</span> ';
            echo '<a href="' . esc_url( get_category_link( $categories[0]->term_id ) ) . '">';
            echo esc_html( $categories[0]->name );
            echo '</a>';
        }

        if ( is_single() ) {
            echo ' <span>/</span> ';
            echo '<span>' . esc_html( get_the_title() ) . '</span>';
        }
    } elseif ( is_page() ) {
        echo ' <span>/</span> ';
        echo '<span>' . esc_html( get_the_title() ) . '</span>';
    }

    echo '</nav>';
}
模板中使用 <?php coowin_breadcrumbs(); ?> 调用。复杂多层分类、WooCommerce 产品分类建议使用插件或继续扩展。

[Pagination] 自定义 WP_Query 分页核心代码

中风险

当页面自己创建 WP_Query 时，必须处理 paged、max_num_pages 和 wp_reset_postdata()。

  • 适用文件：自定义模板文件
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：WP_Query / paginate_links / paged
PHP 
$paged = max( 1, get_query_var( 'paged' ), get_query_var( 'page' ) );

$query = new WP_Query( array(
    'post_type'      => 'post',
    'posts_per_page' => 9,
    'paged'          => $paged,
) );

if ( $query->have_posts() ) :
    while ( $query->have_posts() ) :
        $query->the_post();
        get_template_part( 'template-parts/content', get_post_type() );
    endwhile;

    echo paginate_links( array(
        'total'   => $query->max_num_pages,
        'current' => $paged,
        'prev_text' => '上一页',
        'next_text' => '下一页',
    ) );

    wp_reset_postdata();
endif;
如果固定链接规则异常，保存一次“设置 → 固定链接”。多查询页面尤其要注意不要覆盖主查询。

class My_Page_Settings {

        add_action('admin_init', [$this, 'init_settings']);

    public function init_settings() {
        register_setting('settings_group', 'settings_name');
        add_settings_section('settings_section', '', '__return_false', 'settings_name');

        $id = $args['id'];
        echo '<input type="text" name="settings_name[' . esc_attr($id) . ']" value="' . esc_attr($options[$id] ?? '') . '">';

[v1.0.2] Ajax 表单邮件处理模板

中风险

适用于联系表单、配件计算器结果、展会报名、经销商申请等自定义表单提交。

  • 适用文件：功能插件或 functions.php
  • 代码类型：PHP
  • 更新时间：2026-06-04
  • 标签：Ajax / wp_mail / 表单处理
php 
add_action('wp_ajax_send_custom_form', 'my_send_custom_form');
add_action('wp_ajax_nopriv_send_custom_form', 'my_send_custom_form');

function my_send_custom_form() {
    check_ajax_referer('custom_form_nonce', 'nonce');

    $name = sanitize_text_field($_POST['name'] ?? '');
    $email = sanitize_email($_POST['email'] ?? '');
    $message = sanitize_textarea_field($_POST['message'] ?? '');

    if (!$name || !$email) {
        wp_send_json_error(['msg' => 'Required fields are missing.']);
    }

    $to = 'company@example.com';
    $subject = 'New Website Inquiry';
    $body = '<p><strong>Name:</strong> ' . esc_html($name) . '</p>';
    $body .= '<p><strong>Email:</strong> ' . esc_html($email) . '</p>';
    $body .= '<p><strong>Message:</strong><br>' . nl2br(esc_html($message)) . '</p>';

    $headers = ['Content-Type: text/html; charset=UTF-8'];
    wp_mail($to, $subject, $body, $headers) ? wp_send_json_success() : wp_send_json_error();
}

add_action('pre_get_posts', function ($query) {
    if (is_admin() || !$query->is_main_query()) {
        return;
    }

    if ($query->is_search() || $query->is_author() || $query->is_tag() || $query->is_date()) {
